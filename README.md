# elib_downloader

**elib_downloader** — приложение для сохранения страниц книг из нескольких электронных библиотек. Сейчас основной интерфейс — настольное приложение на **CustomTkinter**. Для некоторых источников необходима учётная запись на сайте библиотеки.

> **Важно.** Проект зависит от сторонних сайтов: их адреса, разметка и правила доступа могут меняться. Приложение не снимает ограничения на доступ, не обходит авторизацию и не гарантирует возможность скачивания каждой книги. Используйте его только для материалов, сохранение которых вам разрешено.

## Быстрый старт

### Windows: готовая сборка

Скачайте подходящий файл из [Releases](https://github.com/gisly/elib_downloader/releases), распакуйте его (если требуется) и запустите `elib_downloader.exe`.

Если готовая сборка устарела или отсутствует, установите приложение из исходников по инструкции ниже. Для библиотек, работающих через Selenium, может потребоваться установленный Google Chrome.

### Windows: запуск из исходников

Рекомендуется Python **3.11**.

```powershell
git clone https://github.com/gisly/elib_downloader.git
cd elib_downloader
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main_gui.py
```

Если PowerShell запрещает активацию виртуального окружения, можно запустить команды через `\.venv\Scripts\python.exe` без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main_gui.py
```

### Linux / macOS: запуск из исходников

Требуются Python **3.11** и установленная поддержка Tk. На некоторых дистрибутивах Linux пакет Tk устанавливается отдельно (например, `python3-tk`).

```bash
git clone https://github.com/gisly/elib_downloader.git
cd elib_downloader
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main_gui.py
```

Для источников, использующих Selenium, потребуется совместимый браузер и драйвер. Автоматическая настройка драйвера зависит от установленной версии Selenium и окружения.

## Как пользоваться

1. Выберите библиотеку в списке **«Источник»**.
2. Если библиотека требует регистрации, введите логин и пароль от *этой библиотеки*.
3. Вставьте URL книги или идентификатор в формате из таблицы ниже.
4. Выберите папку назначения и нажмите **«Скачать / продолжить»**.
5. В правой части окна следите за прогрессом. Кнопка **«Остановить»** прерывает загрузку после текущего сетевого действия, сохраняя уже готовые файлы.
6. Для продолжения выберите **ту же библиотеку, ту же книгу и ту же папку**, затем снова нажмите «Скачать / продолжить». Кнопка **«Открыть папку с файлами»** показывает результат.

## Докачка и защита от потери прогресса

Докачка **включена автоматически** для всех девяти источников. Отдельно включать её не нужно. После обрыва сети или нажатия «Остановить» запустите **тот же идентификатор/ссылку** в **той же папке**. Готовые файлы проверяются на диске; отметка о прогрессе сама по себе не считается доказательством, что файл цел.

- Изображения и PDF записываются через временные файлы (`.part`) и переименовываются только после проверки. Повреждённые завершённые файлы не считаются скачанными.
- Рядом с книгой создаётся `.download_state.json` — состояние для интерфейса (сколько обработано, статус и число пропущенных файлов). В нём **нет паролей или cookies**. Не удаляйте эту папку, если планируете докачать книгу.
- Кнопка «Остановить» останавливает загрузку после текущего запроса. Серверные таймауты могут занимать некоторое время; нет необходимости закрывать процесс принудительно.
- **PRLIB**: готовые страницы повторно не собираются, сохранившиеся фрагменты незавершённой страницы используются повторно.
- **RGO, NLRS, LIBFL, SHPL, KAZNEB**: сохраняются и переиспользуются отдельные изображения страниц. При возобновлении просмотрщик/метаданные могут открыться заново — сами изображения не загружаются повторно.
- **PGPB**: уже скачанные PDF-фрагменты сохраняются до успешной сборки итогового PDF; при обрыве сборка повторяется.
- **NEBCHR**: готовый PDF пропускается; незавершённый PDF продолжает скачиваться через HTTP Range **только если сервер поддерживает диапазоны и предоставляет ETag/Last-Modified**. Иначе для целостности он загружается заново.
- **PDF_READER**: готовый PDF переиспользуется; **незавершённая загрузка в Chrome запускается заново**, поскольку внутренний механизм Chrome/PDF.js не гарантирует продолжение с байта остановки.

Докачка **не обходит** запреты доступа, IP-ограничения или изменения API библиотек. Если источник перестал отдавать страницы, сохранённое останется на диске, но недостающие страницы смогут загрузиться только после восстановления доступа.

### Пример возобновления

1. Вы скачивали `https://www.prlib.ru/item/363162` в `D:\Books`; произошёл обрыв после нескольких страниц.
2. Откройте приложение, укажите ту же ссылку и папку `D:\Books`.
3. Интерфейс покажет найденную незавершённую загрузку (если сохранён файл состояния). Нажмите **«Скачать / продолжить»**.
4. Программа проверит сохранившиеся страницы и докачает только отсутствующие. **Не переименовывайте** каталог `PRLIB_363162` перед продолжением.

### Горячие клавиши в Windows 10 (русская раскладка)

В Windows 10 при русской раскладке поддерживаются Ctrl+C, Ctrl+V,
Ctrl+X и Ctrl+A. Для версий Tk до 8.6.18 приложение использует безопасную
проверку состояния клавиш (`GetAsyncKeyState`) из обычного цикла Tkinter.
Она работает только в активном окне приложения и не устанавливает глобальных
хуков. Для английской раскладки используются стандартные сочетания Tkinter.

**Как проверить:** выделите текст в поле «Идентификатор книги», переключитесь
на русскую раскладку и нажмите Ctrl+C. Вставьте скопированный текст в другой
редактор, например Notepad++.

**Резервный способ:** выделите текст и нажмите **правую кнопку мыши** в поле
ввода, затем «Копировать», «Вставить», «Вырезать» или «Выделить всё».
Копирование и вырезание замаскированного пароля запрещены.

Автоматические тесты проверяют логику опроса, но **фактическую работу горячих клавиш
следует проверить на своём компьютере с Windows 10**. Обновление `.py` не меняет
уже собранный `.exe`: для него требуется повторная сборка через `build.bat`.

Скачивание намеренно выполняется с паузами между запросами, чтобы не создавать чрезмерную нагрузку на сайты библиотек. Крупные книги могут обрабатываться долго.

## Если не скачивается Президентская библиотека (PRLIB)

В поле «Идентификатор книги» можно ввести **номер** (`363162`) или **полную ссылку**
(`https://www.prlib.ru/item/363162`). Например, это запись книги И. И. Огиенко
«Русское литературное ударение» (1914).

Загрузчик использует публично доступные изображения из просмотрщика сайта.
Наличие карточки книги в каталоге **не гарантирует** доступность сканов: часть
материалов можно просмотреть только в электронных читальных залах.

- **HTTP 401/403** — сервер не разрешил запрос. Проверьте, открывается ли
  вкладка «Чтение» в обычном браузере; возможно, необходим доступ к ресурсу.
- **Не удалось получить метаданные** — страница не содержит ожидаемых
  параметров просмотрщика или сервер метаданных недоступен. Это может означать
  изменение сайта либо ограничения для конкретного документа.
- **HTTP 404 на первом фрагменте** — изображение страницы не найдено.
  Если размеры страницы доступны в метаданных, программа теперь рассчитывает
  число фрагментов и сообщает об отсутствии нужного фрагмента, вместо того
  чтобы молча пропускать часть страницы.
- **Сетевая ошибка** — проверьте подключение и доступность `www.prlib.ru` и
  `content.prlib.ru` из той же сети. По одной ошибке нельзя определить, блокирует
  ли сайт IP-адрес или причиной стало изменение API.

В случае ошибки приложите к обращению **ID книги**, текст ошибки и уточнение,
открывается ли вкладка «Чтение» в браузере. Пароли, cookie и токены не публикуйте.

## Если не скачивается РГО

**Ошибка `HTTP 403` не обязательно означает, что сломан загрузчик.** Сервер мог ограничить доступ по IP-адресу или региону, потребовать авторизацию либо отклонить запросы программы. Установить причину *только* по коду 403 нельзя.

Проверка без обхода ограничений:

1. На **том же компьютере и в той же сети** откройте в обычном браузере сайт РГО и конкретную книгу.
2. Убедитесь, что страница просмотрщика действительно открывается и изображения страниц доступны для просмотра. Если доступ закрыт и в браузере, программа тоже не сможет скачать страницы.
3. Скопируйте **полную** ссылку из адресной строки — предпочтительно `/safe-view/...`; можно также попробовать ссылку на карточку `/handle/123456789/ID`.
4. Повторите загрузку один раз и запишите **точный текст ошибки** из приложения. Не запускайте множество параллельных скачиваний.
5. Если ошибка появилась недавно, проверьте официальные сообщения библиотеки о технических работах или обратитесь в поддержку сайта.

| Сообщение | Что означает / что проверить |
| --- | --- |
| `HTTP 403` | Доступ запрещён сервером; возможны ограничения по IP, региону или сессии. Сравните с обычным браузером на той же сети. |
| `HTTP 429` | Сервер ограничивает частоту запросов. Приложение делает ограниченное число повторных попыток с паузами; не увеличивайте частоту. |
| `HTTP 404` | URL устарел либо нужный ресурс больше недоступен. Скопируйте свежую ссылку с сайта. |
| `не является изображением` | Вместо изображения вернулся HTML/другой ответ. Старый загрузчик мог молча сохранить его как `.png`; теперь это явная ошибка. |
| `не удалось определить количество страниц` | Изменилась разметка просмотрщика либо вместо неё вернулась страница ограничения доступа. Нужен пример доступной книги для диагностики. |
| `не удалось подключиться` | Сетевая ошибка, таймаут, DNS/TLS или недоступность сайта. Проверьте соединение. |

**Для сообщения об ошибке в GitHub Issues** приложите: версию программы (или дату сборки), операционную систему, формат ссылки (`/handle/` или `/safe-view/`), воспроизводимые шаги и точный текст ошибки. Можно указать, открывается ли эта книга в браузере из той же сети. **Не публикуйте пароли, cookies, токены доступа и приватные ссылки.**

Реальное устранение IP-ограничения или изменения серверного API требует проверки в окружении, где РГО доступен. Автоматически «чинить» HTTP 403 заменой User-Agent, прокси или агрессивными повторами некорректно.

## Скорость загрузки и оценка времени

Начиная с этой версии, сетевые запросы повторно используют HTTP-соединения
(`requests.Session`). Для независимых файлов включена **небольшая ограниченная
параллельность** — не более трёх активных задач на книгу. При ответе HTTP 429
программа делает паузу с учётом `Retry-After` (если он указан) и временно
снижает интенсивность новых запросов. HTTP 403 не обходится.

| Библиотека | Как ускорено | Одновременных запросов к файлам |
| --- | --- | ---: |
| **PRLIB** | Три потока на отдельные плитки известной сетки; общие соединения; исключена постоянная задержка перед каждой страницей | До **3** плиток |
| **РГО** | Параллельная загрузка независимых изображений; повторное использование cookies соединения просмотрщика | До **2** страниц |
| **SHPL** | Параллельные изображения страниц | До **3** |
| **KAZNEB** | Параллельные изображения страниц | До **3** |
| **PGPB** | Параллельные PDF-фрагменты, затем строго последовательная сборка итогового PDF | До **2** |
| **LIBFL** | Два потока для уже известных JPEG-ссылок; вход через браузер остаётся однопоточным | До **2** |
| **NLRS** | Повторное использование HTTP-соединений; перелистывание через Selenium остаётся последовательным | **1** |
| **NEBCHR** | Повторное использование соединения при получении PDF; докачка по HTTP Range и ограниченные повторные попытки | **1** |
| **PDF Reader** | Частый опрос состояния скачивания в Chrome (раз в секунду вместо раз в 20 секунд), без дополнительной задержки после загрузки просмотрщика | **1**, управляет Chrome |

**Прогресс.** В интерфейсе отображаются скорость передачи, приблизительное
время до окончания и (для PRLIB) число загруженных фрагментов текущей страницы.
Скорость рассчитывается по фактически полученным байтам с начала задачи;
время — *очень приблизительно*, по уже завершённым новым страницам. При
авторизации, сборке PDF, неравномерных размерах страниц и чтении из кеша
индикатор может показывать `—` или существенно ошибаться. Для браузерного
PDF Reader точную скорость в байтах получить нельзя.

**Сохранение и надёжность.** Каждое изображение и PDF проверяются перед
повторным использованием. Файл сначала пишется как `.part`, затем атомарно
переименовывается. Для каждого мелкого фрагмента больше не вызывается
`fsync`: это ускоряет работу с диском, но **не гарантирует сохранность новых
данных при внезапном отключении питания**. После обычного прерывания загрузку
можно продолжить; повреждённый файл будет скачан заново.

**Сайты.** Реальная скорость ограничена сервером, сетью, числом/размером
фрагментов и правилами доступа. Параллельность не поможет при HTTP 403, а
слишком частые запросы могут привести к HTTP 429. Если конкретная библиотека
ограничивает запросы, лучше уменьшить нагрузку, а не увеличивать число потоков.
Здесь выполнены автономные тесты, **не нагрузочное тестирование серверов**.

## Сборка Windows `.exe`

В каталоге проекта после установки зависимостей выполните:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller elib_downloader_gui.spec --clean
```

Либо запустите `build.bat` (он установит зависимости). Результат — **`dist/elib_downloader.exe`**. После изменений исходного кода пересоберите приложение, если пользуетесь `.exe`.

## Для разработчиков

```text
main_gui.py                # обновлённый интерфейс: прогресс, остановка, докачка
clipboard_shortcuts.py     # операции с буфером и контекстное меню
windows_keyboard.py       # Windows: безопасный опрос Ctrl-сочетаний в цикле Tk
sources.py                 # список библиотек и диспетчер загрузчиков
abstract_lib_downloader.py # общие сетевые функции, отмена, прогресс
resume.py                  # проверка файлов, атомарная запись, HTTP Range, состояние
transfer.py                # параллельные задачи, паузы HTTP, скорость и ETA
*_downloader.py            # реализации для отдельных библиотек
rgo_downloader.py          # обработка ссылок и ответов РГО
CHANGELOG.md               # изменения в текущей версии
elib_downloader_gui.spec   # конфигурация PyInstaller
tests/                    # автономные тесты без обращений к библиотекам
```

Старый интерфейс на NiceGUI удалён. Актуальная точка входа — **`main_gui.py`**.

Запуск тестов:

```bash
python -m pip install pytest
python -m pytest -q
```

Автономные тесты проверяют в том числе имитацию обрыва PDF, HTTP Range с ETag, сохранение PDF-фрагментов PGPB, повторное использование изображений KAZNEB/SHPL/RGO и фрагментов PRLIB. Они **не подтверждают доступность живых сайтов**. Проверку полного GUI на Windows и поведение конкретных библиотек необходимо проводить отдельно.

## Что планируется улучшать

- Дополнить поддержку адаптивных ограничений скорости для разных серверов.
- Дополнить проверки докачки интеграционными тестами всех девяти сайтов из реальной сети.
- Рассмотреть веб-интерфейс **поверх того же ядра загрузчиков**, не дублируя логику. У веб-версии нужно отдельно продумать размещение сервера, доступ к файлам, хранение паролей и ограничения сетей, с которых идут запросы к библиотекам.
